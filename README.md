# Loop

A conversation prompt app for partners, family, and friends of people with ADHD. One prompt at a time. No schedule, no pressure.

## What it does

Loop shows a single conversation prompt, randomly selected from 365 prompts across 12 themes. Tap the refresh button for a new one. That's it.

Designed to make it easier to start meaningful conversations without pressure or planning.

## Themes

`attention & focus` · `executive function` · `time perception` · `emotional regulation` · `support & help` · `strengths` · `perimenopause` · `family & relationships` · `memory & forgetfulness` · `sleep & insomnia` · `relationship dynamics` · `creative interests`

## Running locally

```bash
python3 -m http.server 8080
```

Then open `http://localhost:8080`.

## Deploying

Built for GitHub Pages. Push to `main`, then go to **Settings → Pages** and set the source to the `main` branch.

Live at: `https://yourusername.github.io/loop/`
